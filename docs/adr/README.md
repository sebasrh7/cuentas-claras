# Architecture Decision Records

Cada decisión técnica importante se registra aquí como un ADR: un documento corto que explica el contexto, la decisión y sus consecuencias.

## Cómo crear uno

1. Copia [`0000-plantilla.md`](0000-plantilla.md) como `NNNN-titulo-corto.md`, con el siguiente número disponible.
2. Complétalo y ábrelo en el mismo PR que implementa o motiva la decisión.
3. Un ADR aceptado no se reescribe. Si la decisión cambia, se crea uno nuevo que lo reemplaza y se actualiza el estado del anterior.
